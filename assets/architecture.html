The optimization, stated exactly

minimize Σ tariff[h] × grid[h]    subject to   grid[h] + solar[h] − battery[h] = demand[h]  ·  E[h] = E[h−1] + battery[h]  ·  E[23] = Einitial  ·  reserve ≤ E[h] ≤ capacity  ·  −max_discharge ≤ battery[h] ≤ max_charge

Key choices

  • Signed battery flow — one action per hour without binary variables, so it stays a pure LP
  • Lossless model — no invented efficiency, degradation or peak penalty
  • Cost is the only objective — peak is reported, not optimized

Safe failure

  • Provider failure never becomes a fabricated schedule
  • A directive is never relaxed to force a success
  • Errors are static — no input, stack trace or key
  • Unspecified rules fail loudly instead of guessing

  • check_samples — replays the 10 reference plans
  • solve_samples — LP vs published costs
  • Docker — one pullable image, key at run time
